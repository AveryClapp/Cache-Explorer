# Support

Cache Explorer is a community-maintained open-source project. The best support
path depends on what you need.

## Questions and Ideas

Use GitHub Discussions for:

- "How do I use this?" questions.
- Hardware modeling ideas.
- Optimization questions.
- Design discussion before a large PR.

Discussions: `https://github.com/AveryClapp/Cache-Explorer/discussions`

## Bugs

Use the bug report issue form for:

- Crashes.
- Incorrect or confusing results.
- Install/build failures.
- Browser workflow regressions.
- CLI behavior that differs from docs.

Include the smallest reproduction you can share.

## Security

Do not open a public issue for vulnerabilities. See [SECURITY.md](SECURITY.md).

## Maintainer Expectations

This project prioritizes:

- Reproducible reports.
- Safe defaults.
- Honest hardware/model claims.
- Focused pull requests.

Maintainers may close issues that do not include enough information to
reproduce, are duplicates, or are out of scope for the project.
